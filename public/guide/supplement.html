ตัวแปรเก็บค่า ชนิดข้อมูลบอกว่าจัดเก็บและใช้ค่าชนิดใด เช่น จำนวนเต็ม int ทศนิยม double/float ข้อความ string และค่าจริงเท็จ boolean ชื่อมีความหมาย ห้ามเริ่มด้วยตัวเลข และตัวพิมพ์ใหญ่เล็กต่างกัน ตรวจว่ารับข้อความแล้วแปลงเป็นตัวเลขก่อนคำนวณ

Python

C

#include <stdio.h>
int main(void) {
    int age;
    double score;
    if (scanf("%d %lf", &age, &score) != 2) return 1;
    printf("%d %.2f\n", age + 1, score);
    return 0;
}

ใน C scanf ต้องส่งตำแหน่งตัวแปรด้วย & สำหรับตัวเลข และ %lf ใช้รับ double ส่วน printf ใช้ %.2f แสดงทศนิยมสองตำแหน่ง ตรวจผลรับข้อมูลเพื่อไม่ใช้ค่าที่ไม่ได้กำหนด

Java

import java.util.Scanner;

    }
}

7. ฟังก์ชันและ recursion

ฟังก์ชันแบ่งงาน ตั้งชื่อ รับพารามิเตอร์และอาจคืนค่า return ตัวแปรภายในมีขอบเขตของตัวเอง Recursion คือฟังก์ชันเรียกตัวเอง ต้องมี base case และแต่ละขั้นเข้าใกล้ฐาน ไม่เช่นนั้น stack อาจเต็ม

# Python
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)
print(factorial(4))  # 24
/* C: วางฟังก์ชันก่อน main */
int factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}
// Java: วางภายใน class Main
static int factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}

ตัวอย่างนี้สมมติ n เป็นจำนวนเต็มไม่ติดลบและผลไม่เกินช่วงชนิดข้อมูล หาก f(a,b) คืน 1 เมื่อ b≤0 นอกนั้นคืน a×f(a,b−2) แล้ว f(2,9)=2⁵=32 เพราะ b เป็น 9,7,5,3,1 ก่อนถึง −1

Softmax แปลงคะแนน z ของหลายคลาสเป็น pᵢ=e^zᵢ/Σe^zⱼ ผลแต่ละค่าอยู่ระหว่าง 0 ถึง 1 และรวมเป็น 1 ใช้บ่อยกับการจำแนกหนึ่งคลาสจากหลายคลาส เช่น logits [0,0] ให้ [0.5,0.5] แต่คะแนนที่ดูเป็นความน่าจะเป็นอาจยังไม่ calibrated

Expert system ใช้ knowledge base เก็บข้อเท็จจริงและกฎ ส่วน inference engine ใช้กฎอนุมานผล ตัวอย่าง IF ไข้สูง AND ไอ THEN แนะนำให้ประเมินเพิ่มเติม ระบบแบบกำหนดกฎไม่จำเป็นต้องเรียนรู้จากข้อมูล k-NN เป็น lazy learning เพราะมักเก็บตัวอย่างฝึกไว้ แล้วคำนวณระยะและเลือกเพื่อนบ้านตอนทำนาย จึงต้องคิดเรื่องสเกลและต้นทุนการทำนาย

ข้อ 12 · การเขียนโปรแกรมและอัลกอริทึม

  2. เปลี่ยน x > best เป็น x >= best
  3. เปลี่ยน for x in values เป็น for x in values[1:]
  4. เปลี่ยน return best เป็น return x

คำตอบ: เปลี่ยน best = 0 เป็น best = values[0]

เหตุผล: ถ้าข้อมูลเป็น [−8, −3, −5] จะไม่มีค่าใดมากกว่า 0 โค้ดเดิมจึงคืน 0 ซึ่งไม่ได้อยู่ในรายการ เริ่ม best จากสมาชิกแรกทำให้มีค่าตั้งต้นที่ถูกต้อง แล้วเปรียบเทียบสมาชิกทั้งหมดได้ทั้งกรณีค่าบวก ลบ และรายการที่มีตัวเดียว การคืน x คืนเพียงสมาชิกสุดท้าย ไม่จำเป็นต้องเป็นค่าสูงสุด

คำตอบ: Accuracy 99% แต่ recall ของสแปมเป็น 0% จึงยังไม่ตอบโจทย์จับสแปม

เหตุผล: ทำนายถูก 990 จาก 1,000 ฉบับจึงได้ accuracy 99% แต่จับสแปมถูก 0 จาก 10 ฉบับ จึงมี recall 0% เมื่อคลาสไม่สมดุล accuracy สูงอาจซ่อนความล้มเหลวในการตรวจคลาสที่สนใจได้

  2. A เพราะในทั้งห้าตัวมี A มากกว่า
  3. B เพราะสามตัวที่ใกล้ที่สุดมี B สองตัว

คำตอบ: B เพราะสามตัวที่ใกล้ที่สุดมี B สองตัว

เหตุผล: k=3 จึงพิจารณาเฉพาะสามตัวแรก คือ A, B, B และโหวตเท่ากันทุกตัว B ชนะ 2 ต่อ 1 การเลือกเพียงตัวแรกเท่ากับใช้ k=1 ส่วนการนับครบห้าตัวเท่ากับใช้ k=5 ซึ่งไม่ตรงโจทย์

  2. เลือก C เพราะช่องว่าง train กับ validation น้อยที่สุดเสมอ

เหตุผล: กราฟกระจายเก็บคู่ค่าของตัวแปรเชิงปริมาณทั้งสองไว้ในแต่ละจุด จึงเห็นแนวโน้มและจุดที่ห่างจากกลุ่มได้ กราฟที่รวมข้อมูลหรือไม่แสดงตัวแปรหนึ่งจะตอบโจทย์นี้ไม่ได้ และการเห็นความสัมพันธ์ยังไม่ยืนยันเหตุและผล

  3. =COUNTIFS(A2:A100,"A",B2:B100,"ผ่าน")
  4. =SUMIFS(C2:C100,A2:A100,"ผ่าน",B2:B100,"A")

ข้อ 33 · พื้นฐาน ICT และการเพิ่มประสิทธิภาพ

  1. อัตราผ่านเพิ่ม 60% เพราะจำนวนผู้ผ่านเพิ่มจาก 30 เป็น 48 คน
  2. อัตราผ่านลด 20% และยืนยันได้ว่าการอบรมทำให้ผลแย่ลง
  3. อัตราผ่านเพิ่ม 20 จุดเปอร์เซ็นต์ แต่ยังสรุปเหตุและผลไม่ได้
  4. อัตราผ่านลดจาก 60% เป็น 40% และยังสรุปผลเชิงเหตุของการอบรมไม่ได้

คำตอบ: อัตราผ่านลดจาก 60% เป็น 40% และยังสรุปผลเชิงเหตุของการอบรมไม่ได้

  1. status == "ค้าง" or due < today
  2. status == "ค้าง" and due < today
  3. status == "ค้าง" and due <= today
  4. status != "ค้าง" and due < today

คำตอบ: status == "ค้าง" and due < today

เหตุผล: ต้องเป็นจริงทั้งสถานะค้างและวันที่ก่อนวันนี้ จึงใช้ and กับเครื่องหมาย < การใช้ or จะรวมรายการเสร็จที่เลยกำหนดและรายการค้างที่ยังไม่ถึงกำหนด ส่วน <= รวมวันนี้ซึ่งโจทย์ไม่ต้องการ

  1. CPU ช้าเกินไป จึงควรเพิ่มจำนวนคอร์ก่อนตรวจอย่างอื่น
  2. จอภาพแสดงผลช้า จึงควรเพิ่มความละเอียด

  4. พื้นที่ดิสก์มากเกินไป จึงควรลดขนาดพาร์ทิชัน

คำตอบ: RAM ไม่พอกับงานพร้อมกัน ควรลดโปรแกรมที่เปิดหรือเพิ่ม RAM หากเครื่องรองรับ

เหตุผล: RAM เกือบเต็มร่วมกับการสลับข้อมูลลงดิสก์มากและอาการดีขึ้นเมื่อปิดโปรแกรม สนับสนุนว่าหน่วยความจำเป็นคอขวด การลดงานพร้อมกันหรือเพิ่ม RAM ช่วยลดการสลับข้อมูล CPU ที่ใช้งานไม่สูงไม่ได้ชี้ว่าจำเป็นต้องเพิ่มคอร์

ข้อ 40 · พื้นฐาน ICT และการเพิ่มประสิทธิภาพ

ต้องเก็บไฟล์วิดีโอขนาดไฟล์ละ 250 MB จำนวน 120 ไฟล์ บนไดรฟ์ 40 GB โดยกันพื้นที่ 25% ของความจุทั้งหมดไว้สำหรับงานอื่น กำหนด 1 GB = 1,000 MB และไม่คิดพื้นที่ระบบไฟล์ ข้อใดถูกต้อง?

  1. พื้นที่ไม่พอ ขาด 10 GB
  2. พื้นที่พอ และเหลือสำหรับวิดีโออีก 10 GB
  3. พื้นที่พอ และเหลือสำหรับวิดีโออีก 7.5 GB
  4. พื้นที่พอพอดี โดยใช้ส่วนที่จัดให้วิดีโอครบ 30 GB

คำตอบ: พื้นที่พอพอดี โดยใช้ส่วนที่จัดให้วิดีโอครบ 30 GB

เหตุผล: ไฟล์รวม 250×120 = 30,000 MB = 30 GB พื้นที่ที่จัดให้วิดีโอคือ 40×(1−0.25)=30 GB จึงพอพอดี 10 GB ที่เหลือเป็นพื้นที่กันไว้ให้งานอื่น ไม่ใช่พื้นที่วิดีโอที่ยังใช้ได้ตามเงื่อนไข
