# Study guide source

`lessons.html` contains the supplementary lessons. `review.json` contains the original guide's review questions and explanations. The question data in the parent directory contains the two practice sets; each practice item includes a detailed explanation. Run `python public/guide/build.py` to generate printable lesson, review, and question HTML. `original-retypeset.html` preserves the original lessons in the Prompt font, including colored boxes and rules.

Print the generated HTML to A4 PDF with browser print headers disabled. Combine the cover, original lesson pages, supplementary lessons, review questions and practice sets in that order; update bookmarks and page numbers before publishing. Answers appear directly after each question. Code uses a monospace font; mathematical symbols may use a fallback font. Prompt is licensed under the included OFL.txt.
