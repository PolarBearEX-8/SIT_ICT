ข้อ 1 · การเขียนโปรแกรมและอัลกอริทึม

ข้อใดกล่าวถูกต้องเกี่ยวกับอัลกอริทึมเรียงลำดับ?

  1. Bubble Sort มีเวลาเฉลี่ย O(N log N)
  2. Quick Sort ใช้แนวคิดแบ่งปัญหาเป็นส่วนย่อย
  3. Merge Sort มีเวลาแย่ที่สุด O(N log N)
  4. Selection Sort ใช้หน่วยความจำเสริม O(N)

เฉลย: Quick Sort และ Merge Sort

เหตุผล: Quick Sort ใช้ divide and conquer ส่วน Merge Sort มีเวลา O(N log N) แม้ในกรณีแย่ที่สุด โดยทั่วไป Bubble Sort เฉลี่ย O(N²) และ Selection Sort ใช้หน่วยความจำเสริม O(1)

คิดทีละขั้น: ตรวจแต่ละตัวเลือกแยกกัน: Bubble sort โดยทั่วไปเทียบคู่ซ้ำหลายรอบจึงเป็นกำลังสอง ส่วน selection sort แบบปกติเก็บตัวแปรเสริมเพียงไม่กี่ตัว ข้อนี้มีสองตัวเลือกถูก แม้โจทย์ไม่ได้ระบุชัดว่าเลือกได้หลายข้อ

ข้อ 2 · การเขียนโปรแกรมและอัลกอริทึม

ผลลัพธ์ของโปรแกรม Python นี้คืออะไร? numbers = [1, 2, 3, 4, 5, 6] result = 0 for num in numbers: if num % 2 == 0: result += num * 2 print(result)

  1. 30
  2. 42
  3. 12
  4. 24

เฉลย: 24

เหตุผล: เลือกเลขคู่ 2, 4, 6 แล้วคูณสองก่อนบวก: 4 + 8 + 12 = 24

คิดทีละขั้น: เริ่ม result=0 เมื่อ num=2 เปลี่ยนเป็น 4; num=4 เปลี่ยนเป็น 12; num=6 เปลี่ยนเป็น 24 เลขคี่ไม่เข้าเงื่อนไข % 2 == 0

ข้อ 3 · เทคโนโลยีสารสนเทศและการเพิ่มประสิทธิภาพ

ต้องการรวมคะแนนใน C2:C20 เฉพาะแถวที่สถานะใน B2:B20 เป็นคำว่า ผ่าน ควรใช้สูตรใด?

  1. =SUM(B2:B20)
  2. =SUMIF(B2:B20,"ผ่าน",C2:C20)
  3. =COUNTIF(B2:B20,"ผ่าน")
  4. =AVERAGEIF(B2:B20,"ผ่าน",C2:C20)

เฉลย: =SUMIF(B2:B20,"ผ่าน",C2:C20)

เหตุผล: รูปแบบฟังก์ชันคือ SUMIF(ช่วงเงื่อนไข, เงื่อนไข, ช่วงที่จะรวม)

คิดทีละขั้น: B2:B20 เป็นช่วงที่ตรวจคำว่า ผ่าน ส่วน C2:C20 เป็นช่วงที่นำค่ามาบวก โดยตำแหน่งแถวต้องสัมพันธ์กัน COUNTIF จะนับจำนวน ส่วน AVERAGEIF หาค่าเฉลี่ย

ข้อ 4 · วิทยาการข้อมูลและปัญญาประดิษฐ์

ข้อใดเป็นหลักจริยธรรมสำคัญในการใช้ AI อย่างรับผิดชอบ? (เลือกได้หลายข้อ)

  1. ความเป็นส่วนตัว
  2. ความรับผิดชอบ
  3. อคติ
  4. ความโปร่งใส

เฉลย: ความเป็นส่วนตัว ความรับผิดชอบ และความโปร่งใส

เหตุผล: อคติเป็นความเสี่ยงที่ควรตรวจหาและลดผลกระทบ ไม่ใช่หลักจริยธรรมที่ควรส่งเสริม

คิดทีละขั้น: พิจารณาว่าแนวทางใดเป็นสิ่งที่ควรส่งเสริม: ปกป้องข้อมูลส่วนบุคคล กำหนดผู้รับผิดชอบ และเปิดเผยข้อมูลที่จำเป็นต่อการตรวจสอบ ส่วน bias คือความเอนเอียงที่อาจทำให้ผลไม่เป็นธรรม จึงต้องตรวจและลดผลกระทบ

ข้อ 5 · เทคโนโลยีสารสนเทศและการเพิ่มประสิทธิภาพ

เมื่อเปิดโปรแกรมตัดต่อวิดีโอและแท็บเบราว์เซอร์จำนวนมาก เครื่องช้าลง แต่กลับมาทำงานเร็วหลังปิดบางโปรแกรม สาเหตุใดเป็นไปได้มากที่สุด?

  1. RAM ไม่เพียงพอชั่วคราว
  2. CPU เสียหาย
  3. พื้นที่ SSD เต็มเสมอ
  4. การ์ดจอมีอุณหภูมิต่ำเกินไป

เฉลย: หน่วยความจำ RAM ชั่วคราวไม่เพียงพอ

เหตุผล: หลายโปรแกรมใช้ RAM พร้อมกัน เมื่อปิดโปรแกรมจะคืนหน่วยความจำให้ระบบ

คิดทีละขั้น: เมื่อหลายโปรแกรมเปิดพร้อมกัน หน่วยความจำที่ใช้อยู่รวมกันอาจเกิน RAM ทำให้ระบบต้องสลับข้อมูลกับดิสก์มากขึ้น สังเกตว่าอาการดีขึ้นหลังปิดโปรแกรมสนับสนุนสมมติฐานนี้ แต่ยังไม่ใช่หลักฐานว่า CPU เสีย

ข้อ 6 · เครือข่ายและความมั่นคงปลอดภัย

นักเรียนเข้าเว็บธนาคารผ่าน HTTPS บน Wi-Fi ร้านกาแฟ ข้อใดถูกต้อง? (เลือกได้หลายข้อ)

  1. รูปกุญแจยืนยันได้แน่นอนว่าเป็นเว็บไซต์ธนาคารจริง
  2. ผู้ให้บริการ Wi-Fi อาจเห็น IP ปลายทางหรือข้อมูลการเชื่อมต่อบางส่วน
  3. HTTPS รับรองว่าธนาคารเข้ารหัสรหัสผ่านที่จัดเก็บในฐานข้อมูลด้วย
  4. ผู้ดักฟังเครือข่ายอย่างเดียวไม่ควรอ่านข้อความรหัสผ่านที่ส่งผ่าน TLS ได้

เฉลย: ผู้ให้บริการอาจเห็นข้อมูลปลายทางบางส่วน และผู้ดักฟังอย่างเดียวอ่านรหัสผ่านจากการเชื่อมต่อ TLS ไม่ได้

เหตุผล: HTTPS ปกป้องข้อมูลระหว่างทาง แต่ไม่ได้รับรองว่าฐานข้อมูลปลายทางเข้ารหัสข้อมูลขณะจัดเก็บ และควรตรวจสอบชื่อโดเมน/ใบรับรองเสมอ

คิดทีละขั้น: TLS ปกป้องข้อมูลระหว่าง client กับเว็บไซต์ที่เชื่อมต่อ แต่เว็บปลอมก็ขอใบรับรองโดเมนของตนได้ และผู้ให้บริการเครือข่ายยังอาจเห็นข้อมูลการเชื่อมต่อบางส่วนตามเทคโนโลยีที่ใช้

ข้อ 7 · วิทยาการข้อมูลและปัญญาประดิษฐ์

ข้อใดอธิบายความสามารถที่อาจพบในระบบปัญญาประดิษฐ์ได้? (เลือกได้หลายข้อ)

  1. ประมวลผลข้อมูลจำนวนมาก
  2. เรียนรู้รูปแบบจากข้อมูล
  3. ปรับการทำงานตามข้อมูลหรือบริบท
  4. อนุมานหรือให้เหตุผลตามแบบจำลอง

เฉลย: ทั้งสี่ข้อเป็นความสามารถที่พบได้ใน AI บางประเภท

เหตุผล: ไม่ใช่ AI ทุกระบบจะทำได้ครบทุกอย่าง ความสามารถขึ้นกับชนิดของระบบและวิธีออกแบบ

คิดทีละขั้น: โจทย์ถามความสามารถที่อาจพบ ไม่ได้บอกว่าทุกระบบต้องทำได้ทั้งหมด บางระบบเรียนรู้รูปแบบหรืออนุมานจากข้อมูล ส่วนความสามารถจริงขึ้นอยู่กับชนิดระบบและการออกแบบ

ข้อ 8 · การเขียนโปรแกรมและอัลกอริทึม

แนวคิดเชิงวัตถุที่ซ่อนรายละเอียดการทำงานภายในและเปิดให้ใช้ผ่านส่วนติดต่อที่กำหนด เรียกว่าอะไร?

  1. Inheritance
  2. Encapsulation
  3. Polymorphism
  4. Overloading

เฉลย: Encapsulation (การห่อหุ้ม)

เหตุผล: Encapsulation รวมข้อมูลกับการทำงานไว้ด้วยกัน และควบคุมการเข้าถึงรายละเอียดภายในผ่าน interface

คิดทีละขั้น: Inheritance เกี่ยวกับการสืบทอด ส่วน polymorphism คือการใช้อินเทอร์เฟซเดียวกับพฤติกรรมหลายแบบ จึงไม่ตรงคำถามเรื่องควบคุมการเข้าถึงรายละเอียดภายใน

ข้อ 9 · การเขียนโปรแกรมและอัลกอริทึม

การเรียกฟังก์ชันแบบ recursion โดยไม่มีกรณีฐาน (base case) มักทำให้เกิดผลใด?

  1. SyntaxError
  2. Stack Overflow หรือ RecursionError
  3. IndexError
  4. TypeError

เฉลย: การเรียกซ้ำไม่สิ้นสุดจน stack เต็ม

เหตุผล: โปรแกรมจะหยุดด้วยข้อผิดพลาด เช่น Stack Overflow หรือ RecursionError

คิดทีละขั้น: แต่ละครั้งที่เรียกซ้ำใช้พื้นที่สำหรับสถานะการเรียก หากไม่เข้าสู่ base case จะเพิ่มต่อไปจนถึงขีดจำกัดของ runtime หรือ stack; แม้มี base case ก็ต้องทำให้ข้อมูลเข้าใกล้ฐานด้วย

ข้อ 10 · เครือข่ายและความมั่นคงปลอดภัย

ข้อใดถูกต้องเกี่ยวกับการทำสำเนาข้อมูลหรือการซิงก์ไฟล์? (เลือกได้หลายข้อ)

  1. เมื่อดิสก์หนึ่งเสีย ระบบที่ทำ mirrored disk อาจทำงานต่อจากอีกดิสก์ได้
  2. ลบไฟล์ที่ซิงก์ในเครื่องแล้ว สำเนาบนคลาวด์จะไม่ถูกลบตาม
  3. แรนซัมแวร์ที่เข้ารหัสไฟล์ในเครื่องอาจซิงก์ไฟล์ที่ถูกเข้ารหัสขึ้นคลาวด์
  4. การทำ mirrored disk ไม่ได้ป้องกันไฟดับ

เฉลย: ข้อ 1, 3 และ 4

เหตุผล: Mirroring ช่วยรับมือดิสก์เสีย แต่ไม่ป้องกันไฟดับหรือการลบ/เข้ารหัสที่ถูกซิงก์ไปด้วย จึงยังต้องมีระบบสำรองข้อมูลแยกต่างหาก

คิดทีละขั้น: การมีสำเนาพร้อมใช้งานช่วยให้บริการทนดิสก์เสีย แต่การลบหรือเข้ารหัสอาจแพร่ไปทุกสำเนาที่ซิงก์ และไฟดับทำให้บริการหยุดได้ ควรมี backup แยกและทดสอบกู้คืน

ข้อ 11 · เครือข่ายและความมั่นคงปลอดภัย

การหลอกลวงโดยปลอมเป็นบุคคลหรือหน่วยงานที่น่าเชื่อถือเพื่อขอข้อมูลส่วนตัว เรียกว่าอะไร?

ข้อ 13 · เครือข่ายและความมั่นคงปลอดภัย

หลักการสำคัญที่สุดของ Zero Trust Architecture คืออะไร?

  1. เชื่อถือทุกอุปกรณ์ภายในเครือข่าย
  2. ไม่เชื่อถือโดยปริยายและตรวจยืนยันตัวตนทุกการเข้าถึง
  3. ติดตั้ง Firewall เพียงอย่างเดียว
  4. เข้ารหัสเฉพาะข้อมูลที่จัดเก็บ

เฉลย: ไม่เชื่อถือโดยปริยาย และตรวจสอบตัวตน/สิทธิ์ทุกครั้งที่เข้าถึง

เหตุผล: Zero Trust ใช้หลัก verify explicitly และให้สิทธิ์เท่าที่จำเป็น ไม่ถือว่าการอยู่ในเครือข่ายภายในปลอดภัยโดยอัตโนมัติ

คิดทีละขั้น: การอยู่ในเครือข่ายองค์กรไม่ได้ทำให้เชื่อถือโดยอัตโนมัติ ระบบต้องตรวจตัวตน สิทธิ์ และบริบทตามนโยบาย พร้อมจำกัดสิทธิ์เท่าที่จำเป็น Firewall เพียงตัวเดียวไม่ครอบคลุมแนวคิดทั้งหมด

ข้อ 14 · วิทยาการข้อมูลและปัญญาประดิษฐ์

ความท้าทายด้านจริยธรรมที่สำคัญของ Deepfake คือข้อใด?

  1. ละเมิดลิขสิทธิ์เนื้อหา
  2. ใช้พลังงานประมวลผลสูง
  3. บ่อนทำลายความน่าเชื่อถือของสื่อและสร้างข้อมูลเท็จ
  4. ผูกขาดซอฟต์แวร์

เฉลย: บ่อนทำลายความน่าเชื่อถือของสื่อและสร้างข้อมูลเท็จ

เหตุผล: Deepfake อาจทำให้ผู้ชมเข้าใจผิดหรือถูกใช้ปลอมแปลงบุคคล จึงควรตรวจสอบแหล่งที่มาและบริบท

  2. จอภาพแสดงผลช้า จึงควรเพิ่มความละเอียด

  4. พื้นที่ดิสก์มากเกินไป จึงควรลดขนาดพาร์ทิชัน

ข้อ 40 · พื้นฐาน ICT และการเพิ่มประสิทธิภาพ

ต้องเก็บไฟล์วิดีโอขนาดไฟล์ละ 250 MB จำนวน 120 ไฟล์ บนไดรฟ์ 40 GB โดยกันพื้นที่ 25% ของความจุทั้งหมดไว้สำหรับงานอื่น กำหนด 1 GB = 1,000 MB และไม่คิดพื้นที่ระบบไฟล์ ข้อใดถูกต้อง?

  1. พื้นที่ไม่พอ ขาด 10 GB
  2. พื้นที่พอ และเหลือสำหรับวิดีโออีก 10 GB
  3. พื้นที่พอ และเหลือสำหรับวิดีโออีก 7.5 GB
  4. พื้นที่พอพอดี โดยใช้ส่วนที่จัดให้วิดีโอครบ 30 GB

เฉลย: พื้นที่พอพอดี โดยใช้ส่วนที่จัดให้วิดีโอครบ 30 GB

เหตุผล: ไฟล์รวม 250×120 = 30,000 MB = 30 GB พื้นที่ที่จัดให้วิดีโอคือ 40×(1−0.25)=30 GB จึงพอพอดี 10 GB ที่เหลือเป็นพื้นที่กันไว้ให้งานอื่น ไม่ใช่พื้นที่วิดีโอที่ยังใช้ได้ตามเงื่อนไข
