# ICT Challenge 2026

Static guide for the KMUTT ICT Challenge: registration and team rules, knowledge groups, competition rounds, schedule, awards, and FAQ.

## GitHub Pages deployment

The "Deploy static site to GitHub Pages" workflow publishes the public/ folder when changes are pushed to main. It can also be run manually from the Actions tab.

If Pages has not been enabled for this repository, open Settings → Pages and select GitHub Actions as the build and deployment source.

## Update website content

- Edit public/event.json for event dates, eligibility, rounds, schedule, and awards.
- Edit public/topics.json for the four knowledge groups.
- Edit public/faq.json for questions and answers.
- Edit public/index.html for layout and styling.

After committing and pushing changes to main, GitHub Actions publishes the site.
